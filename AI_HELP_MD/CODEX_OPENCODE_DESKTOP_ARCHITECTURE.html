Electron Main

桌面主进程负责 Electron 生命周期、窗口、菜单、更新、日志、协议处理，并在启动时拉起本地 sidecar server。

  • 入口是 `packages/desktop/src/main/index.ts`。
  • 分配 `127.0.0.1` 随机端口。
  • 通过 `utilityProcess.fork()` 启动 sidecar。

1. Electron Main 启动

初始化日志、证书、代理、单实例锁和桌面协议，然后准备启动本地服务。

通信方式

OpenCode 桌面端不是只用一种 IPC。主业务链路是 renderer 到本地 server 的 HTTP / SSE / WebSocket；桌面壳能力则走 Electron IPC。
