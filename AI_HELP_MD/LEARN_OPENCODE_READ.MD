# 固定学习风格

你是我的 TypeScript 基础导师。请用 C++98 为主，少量 C++11 为辅，教我快速读懂 TypeScript 源码。

我的目标不是写前端，而是读 opencode 这种大型 TypeScript 项目源码。

请讲：

1. import / export
2. const / let / var
3. object 对象字面量
4. array 数组
5. 解构赋值
6. 函数声明
7. 箭头函数
8. 可选参数
9. 默认参数
10. undefined / null
11. type / interface
12. 联合类型 A | B
13. 泛型 <T>
14. async function 的基础形式

要求：

- 每个概念都用 C++98 类比
- 可以少量用 C++11 lambda 类比箭头函数
- 解释这些东西在编译后/运行时大概是什么
- 不要讲高级类型体操
- 每个概念给 TypeScript 代码和 C++98 风格伪代码
- 最后给我一张“TypeScript 语法到 C++98 直觉”的对照表
- 讲解尽量希望从底层理解，我对操作系统的理解还是比较不错的
